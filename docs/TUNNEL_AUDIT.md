и флаги effective + permitted. Имена в пути, похожие имена и permitted-only
больше не дают ложную готовность. Добавлены регрессионные тесты.
README приведён в соответствие с Linux strict_route=true, auto_redirect=false.
Schema test поддерживает AGP_SINGBOX_BIN для проверки установленного helper.

Проверки: go test -race ./..., go vet ./..., сборка Linux — успешно.
Установленный sing-box 1.14.0 успешно проверил сгенерированный конфиг.

Реальный запуск на хосте через amn0 блокируется routing.ownership_collision:
приоритет 19000 уже занят правилом к таблице 20229. Также присутствуют
правила 19001, 19002, 19003, 19010, включая detached antigravity-tun.
При проверке процесса sing-box и интерфейса antigravity-tun не было.
Это соответствует оставшемуся состоянию маршрутизации; принадлежность
следует подтвердить журналом восстановления перед удалением.
Правила не удалялись. sudo требует интерактивной авторизации.

Добавлен opt-in TestLinuxAgentTunnelHostRuntime: создаёт реальный TUN,
проверяет listener и active journal, затем вызывает StopAndWait через cleanup.
Тест требует AGP_HOST_TUN_SMOKE=1, AGP_SINGBOX_BIN и AGP_TEST_VPN_INTERFACE.
TMPDIR должен находиться на том же filesystem, что helper, поскольку тест
сохраняет его capabilities жёсткой ссылкой. Запускать только после устранения
конфликта маршрутов; тест временно изменяет маршрутизацию хоста.

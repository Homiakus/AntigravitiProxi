SAFE MODE

Process-only proxy без изменения WinINET/WinHTTP и системного proxy. Подходит как первый режим и не вмешивается в сеть других приложений.

Уровень 2
AGENT TUNNEL
Transparent transport

Для случая, когда OAuth/регистрация работают, а агент завершается с Agent execution terminated due to error. На Linux подготовка теперь выполняется автоматически: приложение проверит TUN, при необходимости загрузит модуль, установит capability tooling и через системный PolicyKit запросит только узкие права для managed sing-box.

Подготовка одним действием Пароль не читается и не хранится приложением — авторизацию выполняет ОС.

Уровень 1

SAFE MODE

Лёгкий process-only proxy. Сначала используйте его: WinINET/WinHTTP и системные маршруты не меняются, Fusion 360 не затрагивается.

AGENT TUNNEL · уровень 2 Agent transport

Используйте, если регистрация/OAuth проходят, но агент выдаёт Agent execution terminated due to error. Режим поднимает sing-box TUN, перехватывает transport/DNS и направляет процессы Antigravity/language_server через выбранный VPN. Остальные приложения по строгой process-policy идут через system-direct; включённый domain fallback явно помечается как ослабление изоляции.
